LifeGit 后端 - 快速启动指南
====================================

【前置条件】
1. 已安装 Python 3.8+ (https://www.python.org/downloads/)
   - 安装时务必勾选 "Add Python to PATH"
2. 已安装 MySQL 5.7+ 或 8.0
   - 下载: https://dev.mysql.com/downloads/installer/
   - 安装时记住 root 密码

【三步启动】

步骤 1: 初始化数据库(只需执行一次)
----------------------------------
打开 MySQL 命令行(开始菜单搜索 "MySQL 8.0 Command Line Client"):
    mysql -u root -p
    (输入你的 MySQL 密码)
进入后执行:
    mysql> source C:/Users/lenovo/Desktop/LifeGit-backend/schema.sql
    mysql> exit

或直接命令行执行:
    cd C:\Users\lenovo\Desktop\LifeGit-backend
    mysql -u root -p < schema.sql


步骤 2: 配置数据库密码(只需执行一次)
----------------------------------
用记事本打开: C:\Users\lenovo\Desktop\LifeGit-backend\config.py
找到这行: password: '在这里填入你的MySQL密码'
改为你的实际 MySQL 密码,例如: password: '123456'
保存文件


步骤 3: 启动后端服务
----------------------------------
方式 A(推荐): 双击运行 start.ps1
方式 B: 在文件夹空白处按 Shift+右键 -> 打开 PowerShell,执行:
    powershell -ExecutionPolicy Bypass -File start.ps1
方式 C(手动):
    cd C:\Users\lenovo\Desktop\LifeGit-backend
    pip install -r requirements.txt
    python app.py


【验证成功】
----------------------------------
浏览器访问: http://localhost:5000/api/health
看到: {"code":0,"message":"ok"}
说明后端 OK!


【前端联调配置】
----------------------------------
1. 微信开发者工具打开: C:\Users\lenovo\Desktop\LifeGit-frontend\LifeGit
2. 详情 -> 本地设置 -> 勾选 "不校验合法域名、web-view、TLS 版本以及 HTTPS 证书"
3. 重新编译,登录页测试


【常见问题】
----------------------------------
Q: "数据库连接失败"
A: 1) 确认 MySQL 服务已启动(任务管理器->服务->找 MySQL80)
   2) 确认 config.py 密码正确
   3) 确认已执行 schema.sql 建表

Q: "pip 命令找不到"
A: 重装 Python,勾选 "Add Python to PATH"

Q: 微信小程序还是显示"网络连接失败"
A: 1) 确认后端窗口没关闭(关闭即停止服务)
   2) 详情->本地设置,确保勾选了"不校验合法域名"
   3) 真机预览需把 api.js 中 localhost 改为电脑局域网 IP

Q: 端口 5000 被占用
A: 修改 app.py 最后一行的 port=5000 为其他端口
