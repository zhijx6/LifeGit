================================================================
 LifeGit 后端服务器部署指南
 服务器: 阿里云 ECS  118.31.38.183  (Ubuntu 22.04, 2核2G)
 本指南共 5 步,照着从上往下执行即可,大约 10 分钟
================================================================

【第 0 步】阿里云控制台放行端口 (一次性,2 分钟)
----------------------------------------------------------------
1. 打开阿里云控制台 → 云服务器 ECS → 实例
2. 点你的实例 → 「安全组」标签 → 点安全组 ID → 「配置规则」
3. 「手动添加」2 条入方向规则:
   协议类型: 自定义TCP   端口范围: 80/80     授权对象: 0.0.0.0/0
   协议类型: 自定义TCP   端口范围: 443/443   授权对象: 0.0.0.0/0
4. 保存 (22 端口默认已放行,不用管)

【第 1 步】在你自己的 Windows 电脑上打包代码
----------------------------------------------------------------
打开 PowerShell,执行 (直接复制整段):

  tar -czf "$env:USERPROFILE\Desktop\lifegit-backend.tar.gz" --exclude=.venv --exclude=__pycache__ -C C:\Users\lenovo\Desktop LifeGit-backend

会在桌面生成 lifegit-backend.tar.gz

【第 2 步】上传到服务器
----------------------------------------------------------------
PowerShell 继续执行 (会提示输密码,输入你买服务器时设置的 root 密码):

  scp "$env:USERPROFILE\Desktop\lifegit-backend.tar.gz" root@118.31.38.183:/root/

> 如果忘了 root 密码: ECS 实例页 → 「重置密码」→ 重启实例生效

【第 3 步】SSH 登录服务器并执行一键部署
----------------------------------------------------------------
PowerShell 执行:

  ssh root@118.31.38.183

登录成功后 (命令行变成 root@iZbp...#),依次执行:

  tar -xzf /root/lifegit-backend.tar.gz -C /opt/
  cd /opt/LifeGit-backend
  bash deploy.sh

脚本会自动完成: 装环境 → 建库建表 → 装依赖 → 配置开机自启 → 配 Nginx → 健康检查
最后看到 "部署成功! 后端已在 80 端口对外服务" 即完成。
(中途如果卡在 apt 或 pip 下载,是网络慢,等它跑完即可)

【第 4 步】验证部署
----------------------------------------------------------------
在自己电脑浏览器打开:

  http://118.31.38.183/api/health

看到 {"code":0,"message":"ok"} 就说明后端已上云。

【第 5 步】小程序前端切换到云服务器
----------------------------------------------------------------
1. 修改 C:\Users\lenovo\Desktop\LifeGit-frontend\LifeGit\miniprogram\utils\api.js
   第 4 行 BASE_URL 改为:

     const BASE_URL = 'http://118.31.38.183';

2. 微信开发者工具重新编译 (「不校验合法域名」保持勾选)
3. 登录测试 → 走的就是云服务器了

================================================================
常用运维命令 (在服务器上执行)
================================================================
  查看后端日志:   journalctl -u lifegit -n 50 --no-pager
  重启后端:       systemctl restart lifegit
  重启 Nginx:     systemctl restart nginx
  改了代码重新上传后: systemctl restart lifegit

重要说明
